# 🌹 Love.css – Blooming Rose Animation

A beautiful romantic web project that brings a rose to life with a soft glowing animation, layered petals, falling flower petals, and a heartfelt message. This mini experience is built with pure HTML, CSS, and JavaScript.

## ✨ Highlights

- 🌸 Elegant rose bloom animation
- 💖 Romantic love-themed design
- 🌙 Ambient lighting and dreamy background
- 🪷 Animated stem, leaves, and petals
- ✨ Falling petal effect for added atmosphere
- 📱 Responsive layout for smaller screens

## 🧩 Project Structure

```bash
Rose/

```
